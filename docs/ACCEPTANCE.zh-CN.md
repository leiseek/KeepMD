**KeepMD 验收约定与基准方案**

版本：初始验收约定，2026-10-02。本文保留规划口径；当前实现、实测结果和未测边界见 [交付验证报告](VALIDATION.zh-CN.md)，不由此文件自动推定所有平台均已通过。阶段安排见 [ROADMAP.md](../ROADMAP.md)。

**硬约束与暂定基线**

- Windows 原生应用。运行时不依赖 Electron、Tauri、WebView2、CEF、Qt WebEngine 或隐藏的无头浏览器；图表、导出和异常回退也遵守此要求。
- 默认进入阅读。阅读行为不重写源 Markdown 文件。
- 首版开发和性能基线为 Windows 11 x64；Windows 10 22H2 x64 列为兼容性验证目标，通过前不宣称已支持；ARM64 后续安排。
- 100%/125%/150%/200% DPI，中英混排、emoji、中文路径为必验项。
- 语义正确、资源可回收与性能共同验收。功能未实现时使用“待实现”，语法不支持时明确展示原文和原因。

**v0.1 阅读兼容矩阵**

| ID | 范围 | 验收方法 |
| --- | --- | --- |
| MD-01 | 标题、段落、粗斜体、删除线、行内代码、转义和实体 | 对照选定 CommonMark 规范及扩展样例；文字和层级正确 |
| MD-02 | 有序/无序/嵌套列表、引用、分隔线 | 紧凑与松散列表、连续引用的缩进和间距正确 |
| MD-03 | 围栏代码、缩进代码、超长代码行 | 空白保留；复制代码不混入工具栏文字；横向查看可达 |
| MD-04 | 链接、图片链接、引用式链接、自动链接 | 引用定义在正文之后时仍正确；点击命中正确 |
| MD-05 | 常见 GFM 表格和任务列表 | 对齐、行内样式和宽表格可读；任务项先提供只读状态 |
| MD-06 | PNG/JPEG/BMP、本地相对路径 | 中文/空格路径可用；损坏和缺失图片有占位；大图按需解码 |
| MD-07 | UTF-8、UTF-8 BOM、UTF-16 BOM、CRLF/LF | 编码识别确定；未知编码显示明确状态；正文不出现替换乱码 |
| MD-08 | HTML、未知围栏语言、暂不支持扩展 | 有界、可理解地显示原文或占位；不静默丢正文 |
| READ-01 | 选择、跨段复制、全选、Ctrl+C | 组合字符和 emoji 不被截断；复制不触发整篇几何排版 |
| READ-02 | 全文查找、上/下一个匹配、目录跳转 | 页外结果可达；标题重名锚点行为确定 |
| READ-03 | 缩放、调整窗口、深浅主题、跨屏 DPI | 文本清楚、命中位置正确，阅读锚点不大幅跳动 |
| READ-04 | 打开、拖入、本地 Markdown 链接、前进后退 | 路径解释正确，恢复阅读位置，错误文件不破坏当前会话 |
| READ-05 | 外部修改刷新、快速切换文件 | 连续变化合并处理；旧解析和图片结果不进入新文档 |
| READ-06 | 键盘焦点与导航 | Tab、方向键、PageUp/Down、Home/End 可用；焦点可见 |

“常见 GFM”按此矩阵逐项验收，不宣称整个 GFM 生态全部支持。公式、脚注、Wiki 链接、复杂 HTML/CSS、SVG 图片全特性、动图、远程图片自动加载与代码块全语言高亮均不属于 v0.1 的必要范围。代码块基础显示是必要范围；高亮作为可独立添加的能力。

**v0.1 Mermaid 流程图契约**

目标是下列语法子集。对不支持的新语法和图表类型，显示源代码与提示；保持源文件可在其他工具继续使用。Typora 的 `flow` 方言不自动归入 Mermaid 兼容范围。

| ID | 必须覆盖 | 判定点 |
| --- | --- | --- |
| FLOW-01 | `flowchart`、`graph`；TD/TB/BT/LR/RL | 方向正确、节点 ID 稳定 |
| FLOW-02 | 矩形、圆角、菱形、圆形 | 标签不溢出，边连接到对应节点边界 |
| FLOW-03 | 普通箭头、无箭头、虚线、边标签、链式连接 | 节点/边数量和连接关系正确，无静默丢边 |
| FLOW-04 | 中文、空格、引号、常见换行标签 | 字体回退正确，文本测量与实际显示一致 |
| FLOW-05 | 一层 subgraph、组间连接 | 成员归属和可读性正确；嵌套分组进入后续范围 |
| FLOW-06 | 分支、汇合、回边、自环、多个连通分量 | 所有边可识别，布局终止；相同输入结果稳定 |
| FLOW-07 | 常见 `classDef` / `class` / `style` | 仅承诺填充色、线色、文字色和线宽；未知属性有诊断 |
| FLOW-08 | 缺失节点定义、半输入、语法错误、未知类型 | 原文可见；没有崩溃、假成功或错误连接的图 |
| FLOW-09 | 50/200/1000 节点、密集边、深分组输入 | 正常范围可渲染；超预算明确回退，正文仍可交互 |
| FLOW-10 | 多图、主题/DPI 改变、重新打开、文件快速变化 | 缓存命中合理，无过期结果、资源悬挂或持续增长 |

将每类扩成多份小样例，首轮合计至少 30 个，优先使用用户真实文档，合成语料补齐边界。先验证结构语义，再验证几何与视觉：节点/边正确、中文可见、布局可读；不要求与浏览器输出逐像素相同。图中文字的直接选择与全文搜索作为后续增强，首版须能复制图表源码。

普通自动处理范围暂按单图最多 200 节点、400 边试验，最终值由 P0 实测确定。1000 节点样例主要验证资源控制与回退，不作为必须快速渲染的承诺。若库不支持可协作取消，不能用“丢弃结果”冒充计算已经停止；可选择限制工作量，或采用按需启动、可终止的原生工作进程。

**性能语料与测量条件**

| 语料 | 内容 | 目的 |
| --- | --- | --- |
| S100 | 100 KiB 中英混排，无图片和图表 | 启动、基础内存、空闲 CPU |
| M1 / L10 / L50 | 1/10/50 MiB；常规段落和标题 | 文件大小扩展、首屏、滚动、目录、查找 |
| PATHO | 单个超长段落、巨大代码块、5000 行表格、大型嵌套列表 | 验证单块不会绕过调度预算 |
| IMG100 | 100 张可复现的大图；记录尺寸与解码总量 | 验证视口调度、在途任务和实际位图驻留 |
| FLOWSET | 30+ 小图、50/200 节点图和超预算图 | 兼容性、图表延迟、取消、缓存 |
| MIX | 图片、表格、20 张图和中文混合 | 真实阅读和资源竞争 |

合成语料固定生成器版本、随机种子和文件哈希；大文件按需生成，不提交冗余二进制素材。每份运行结果记录程序提交、Release 构建参数、OS、CPU、内存、GPU/驱动、显示缩放、字体和测试日期。

新进程/已有进程、文件缓存温热/经过明确冷缓存准备分别测量。不能把连续启动多次称为冷启动；不通过关闭杀毒来美化正式结果。记录从启动器发起请求到正文首屏提交的时间，同时验证可交互状态；空窗口或加载提示不算正文首屏。图表未就绪时另记“可见内容全部就绪”。

同条件重复至少 30 次，记录原始数据、p50、p95、最大值；30 次的 p95 只作初筛，最终结论必要时增加样本，避免小样本百分位过度精确。记录明显异常原因，但不静默剔除慢样本。

**首轮目标与发布门槛**

以下数字是待验证预算。P0 产出基线后冻结正式门槛；修改预算时记录原因，不通过改数字隐藏退化。

| 指标 | 首轮目标 | 口径 |
| --- | --- | --- |
| S100 温热缓存首屏 | p95 ≤ 100 ms | 新进程；正文可见并验证能响应 |
| S100 冷缓存首屏 | 争取 p95 ≤ 250 ms | 单独说明冷缓存准备方式；无法可靠准备就标记未测 |
| S100 稳态内存 | Private Bytes ≤ 40 MiB | 进程树总量；完成后台任务后测；GPU 单独报告 |
| 空闲 CPU | 连续 30 秒接近空闲基线 | 同时报告 CPU 时间增量与每秒重绘次数，无长期无效帧循环 |
| 滚动 | 60 Hz 下争取帧间隔 p95 ≤ 16.7 ms、p99 ≤ 33.3 ms | 单独记录输入延迟和超过 100 ms 的停顿；120 Hz 后续目标 |
| 50 节点常见图 | 布局计算 p95 ≤ 100 ms | 不含首次进程启动；图表端到端时间另记 |
| 大文档 | 首屏、取消和查找的正式数值由 P0 确定 | 不能只记录解析时间；50 MiB 为压力层，10 MiB 为首版验收层 |
| 资源回收 | 多轮打开/缩放/关闭后稳定在可解释区间 | 检查活跃对象数、句柄和 Private Bytes 趋势；不要求分配器立即归还所有页 |

在 S100 基础占用之外，图片/图表/布局缓存按内容分配独立预算，不能把 40 MiB 小文档目标套到全分辨率大图。需要同时记录：源文本、块模型、文字布局对象、CPU 位图、GPU 位图、等待队列、运行中任务的估算量。资源管理器里的预算必须包括所有强引用，而不只是缓存容器里还能查到的条目。

Working Set、Private Bytes、GPU 专用/共享内存分别报告，不直接相加。帧时间/呈现延迟、布局耗时、纯解析耗时分开；计时器与空闲任务也要计入 CPU 成本。发生新退化时复测对应场景，避免每次小改都重跑完整长基准。

**编辑阶段的额外验收**

v0.2 才引入编辑。必须验证中文输入法组合、撤销/重做、复制粘贴、查找替换、源码换行和 BOM 保留、UTF-8/UTF-16 转换、未保存提示、写入失败以及外部修改冲突。保存使用临时文件与替换策略，并验证失败时原文件仍可读。未编辑时不对源码做格式归一化；阅读模式不创建编辑器缓冲与撤销栈。

**必须留存的证据**

P0 开始生成 `bench/results/` 的原始记录和摘要；兼容性样例放入 `tests/fixtures/`，图表支持清单随实现更新。视觉截图固定字体/DPI，重点检查布局错误，不采用跨 GPU 的严格逐像素判等作为唯一标准。尚未具备的测量项必须标“未测”，不得填入竞品宣传数字。
