- Plan：阅读同级 prompt-flow/native 的 UI、快捷键、JSON 持久化与托盘实现；确认其没有模板库、AI 服务或自动发送功能。
- Exec：独立提示词服务／窗口，原生 RichEdit 输入与 KeepMD 实时预览，源 Markdown 复制收起、焦点返回、草稿自动保存、旧 JSON 导入、Markdown 载入导出、托盘、单配置实例、置顶／透明度与显式登录启动。
- Review：保留源码首尾空白；按需加载与释放预览资源；组合键使用 RegisterHotKey，双 Ctrl 可选 Raw Input；没有移植旧应用的常驻 200 ms 轮询或全局钩子。当前系统 Ctrl+Alt+P 已被占用，默认改为经验证可注册的 Ctrl+Alt+Space。
- Fix：失败注册保留旧快捷键；剪贴板忙不收起；文件锁定与外部修改停止覆盖；损坏草稿不被空文本替换；Esc 优先交给正在组词的输入法。重启与实例转发使用独立配置，不覆写阅读器文件；复核发现向普通阅读实例转发 --resident 时未开启常驻，已补齐参数转发及独立回归。

- Resource：静默常驻时不创建 RichEdit，隐藏后停止预览计时器并释放渲染资源。小草稿观察记录与阅读器 30 次新进程温热缓存复测均绑定最终 EXE 哈希，见验证报告。

- Deliver：0.3 最终 EXE 820,736 字节，132 项核心检查、17 组提示词端到端检查及阅读／编辑／导航／DPI／输入法／压力回归通过。100 KiB 温热缓存新进程启动 p95 84.76 ms，Private Bytes 中位数 15.26 MiB；新启动未唤起的提示词常驻 4.47 MiB，编辑并收起后 7.61 MiB（小草稿单次观察）。便携 ZIP 26 个成员校验通过，解压后真实阅读及提示词复制保存通过。最终 SHA-256 与原始证据见 bench/results/release-summary.json 和 package.json。
