# Prompt Flow 集成说明

本次调研对象是本地同级目录 `D:\Workspace\prompt-flow`，不是微软的 Azure Prompt Flow。阅读了 `native/main.cpp`、`ui.cpp`、`hotkey.cpp`、`config.cpp` 及头文件和构建配置。该项目为 C++17 / Win32 应用，没有浏览器渲染。KeepMD 按其实际操作流程重新实现模块，未复制它的程序、图标或源码文件，也不依赖原项目安装。

## 功能对应

| 同级 Prompt Flow 的能力 | KeepMD 0.3 的实现 |
| --- | --- |
| 托盘静默启动，单实例 | `--resident`；每份配置只有一个提示词服务，`--prompt` 转发到现有实例 |
| 全局组合键 / 双击左 Ctrl | 默认 Ctrl+Alt+Space；可自定义，保留 LCtrl x2 选项 |
| 多行文本输入 | 按需加载 Windows RichEdit；支持中文输入法、撤销、软换行、Markdown 源码 |
| 再按快捷键或 Esc 自动复制并隐藏 | 保留此流程，增加 Ctrl+Enter；返回唤起前的窗口，由用户 Ctrl+V 粘贴 |
| 复制按钮、清空、字数和行数 | 原生按钮；清空可撤销；显示 UTF-16 单元数和逻辑行数 |
| 草稿及窗口偏好持久化 | 独立 UTF-8 `.prompt.md` 和 `.prompt.ini`；防抖保存、原子替换、写入失败提示 |
| 置顶、30–100% 不透明度、右侧定位 | 设置菜单；按唤起前窗口所在显示器的工作区定位 |
| 当前用户登录时启动 | 设置菜单显式启用；注册命令包含引号和配置路径，关闭常驻时移除该配置的启动项 |
| JSON 配置 | 文件菜单可导入旧 JSON 的草稿、快捷键、置顶与透明度；不修改旧文件、不继承自启动 |
| 无 Markdown 渲染 | 新增 KeepMD 原生实时预览，包括约定的 Mermaid flowchart/graph 子集 |
| 无 Markdown 文件入口 | 新增 Markdown 载入与导出，草稿可用普通编辑器读取 |

原项目没有模板库、提示词历史、变量插值、AI API 或自动发送功能。本次没有把这些描述成已有能力。复制的是完整 Markdown 源码，保留缩进、空白行和结尾换行，统一为 LF；与旧工具不同，不裁剪首尾空白。不会模拟粘贴或 Enter 提交。

## 架构与资源

`prompt_model` 负责快捷键语法、双 Ctrl 状态机、偏好、旧 JSON 导入和自启动命令；`prompt_window` 管理独立窗口、托盘、焦点与剪贴板。读取器文档、编辑撤销栈与提示词草稿分开。

普通组合键使用 Windows [`RegisterHotKey`](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey) 和 `MOD_NOREPEAT`。先注册新键，成功后才撤销旧键；失败时保留旧配置。程序运行时可全局唤起，退出后不占用快捷键。关闭阅读器常驻默认关闭，登录启动默认关闭。

双 Ctrl 通过可选 Raw Input 输入接收实现，没有默认全局键盘钩子。两次完整的左 Ctrl 按下/松开需在 350 ms 内完成，按住、自动重复或夹杂其他按键不会按双击处理。发现旧 Prompt Flow 的窗口类仍存在时，拒绝启用该模式并说明原因，避免两个工具同时唤起；组合键可以与旧工具共存。

提示词窗口及热键服务很轻。首次唤起才创建 RichEdit、按钮、预览以及后台解析线程。250 ms 输入防抖更新预览，800 ms 防抖保存草稿；使用有界任务队列、取消标记与版本号，过时结果不会覆盖新输入。收起时取消预览、释放 DirectWrite/Direct2D/图表缓存，保留编辑文本与撤销记录。隐藏阅读器的文件刷新计时器同时停用。稳定空闲不运行提示词周期轮询计时器。

提示词上限为 1 Mi UTF-16 单元；Markdown 渲染与图表仍受 KeepMD 原有预算限制。大于上限、无效编码、NUL 或损坏的草稿不会被空白草稿覆盖。保存失败时保留输入，磁盘草稿外部变化时停止覆盖，可导出内存版本；关闭时可取消或明确放弃未保存输入。数据为本地明文文件。

预览可选择复制渲染后的文字；工具栏“复制全文”和“复制并收起”始终使用源码。提示词预览中的链接目前不执行跳转，本地图片相对草稿所在目录解析。没有引入浏览器或联网服务。

## 验证与范围

`tests/core_tests.cpp` 覆盖快捷键校验、双 Ctrl 时序、旧 JSON 转义/中文/emoji/损坏输入、设置往返与隔离注册表中的自启动添加/删除。`tools/test_prompt.py` 使用真实全局快捷键、独立进程的原生粘贴目标、Windows 文件对话框和本机中文输入法，验证唤起、焦点、原文复制、冲突恢复、单实例、保存、导入导出、重启和空闲。

本机旧 Prompt Flow 正在运行，因此未向桌面注入双 Ctrl 的完整唤起序列；已验证该冲突处理、双 Ctrl 状态机和其他真实组合键流程。使用者退出旧工具后可选择双 Ctrl；不能将这项未做的实机路径描述为已通过。物理跨显示器 DPI 切换和其他 Windows 版本仍未验证。最终执行记录与资源数值见 [交付验证报告](VALIDATION.zh-CN.md) 和 `bench/results/prompt-e2e.json`。
