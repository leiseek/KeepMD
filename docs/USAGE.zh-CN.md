**KeepMD 0.2 使用说明**

这是一个 Windows 原生 Markdown 阅读器，附带轻量源码编辑。解压便携包后运行 `keepmd.exe` 即可。已验证环境为 Windows 11 x64；Windows 10 和 ARM64 未纳入本次实机验证。

**打开与阅读**

打开、拖入 Markdown 文件，或从命令行传入文件路径。支持 `.md`、`.markdown` 和独立 Mermaid 文件 `.mmd`。文件菜单提供最近文件；阅读位置、缩放、宽度和主题保存在 EXE 旁的 `keepmd.ini`，使用 UTF-8 编码。

“添加到打开方式”将 KeepMD 加入当前用户的 Markdown 候选程序列表，不修改现有默认程序。选择此项后，可自行通过 Windows 的“打开方式”或默认应用设置选定它；移动便携目录后需重新添加路径。

| 操作 | 快捷键 / 入口 |
| --- | --- |
| 打开 / 新建 | Ctrl+O / Ctrl+N |
| 目录 | F9 |
| 查找、下一个、上一个 | Ctrl+F、F3、Shift+F3 |
| 返回 / 前进 | Alt+Left / Alt+Right 或工具栏箭头 |
| 页面滚动 | 方向键、PageUp/Down、Home/End、滚轮 |
| 缩放 / 重置 | Ctrl+滚轮、Ctrl+加减号、Ctrl+0 |
| 深浅主题 | Ctrl+D |
| 阅读宽度 | 工具栏“阅读宽度” |
| 选择与复制 | 鼠标拖选、Ctrl+A、Ctrl+C |
| 阅读 / 源码编辑 | F6 |
| 保存 / 另存为 | Ctrl+S / Ctrl+Shift+S |
| 查找替换 | 编辑模式 Ctrl+H |
| 重新读取磁盘文件 | F5 |

目录、查找与复制使用文档文本，不要求先对整篇文章完成字体排版。文件被外部修改时，阅读模式自动刷新；编辑模式保留当前内容并提示磁盘变化。正文中的本地 Markdown 链接在应用内导航；点击 HTTP(S) 链接交给系统默认浏览器。

**Markdown 范围**

已实现标题、段落、粗体、斜体、删除线、行内代码、引用、嵌套列表、围栏与缩进代码块、链接和引用式链接、常见 GFM 表格及只读任务列表。本地 PNG/JPEG/BMP 等由 Windows WIC 解码；无法处理的图片显示占位和原因。表格可横向阅读，复制表格文本时使用制表符分隔单元格。

阅读不会改写 Markdown。正文复制为可读文本；源码模式提供完整原文。HTML 作为原文展示，未知围栏语言仍显示代码。公式、脚注、Wiki 链接、完整 HTML/CSS、SVG 全特性、动态图和远程图片自动下载不属于本版范围。

超长段落和超长代码行会拆成有限大小的显示片段。分片处可能提前换行，复制内容保持连续，不向原文件插入换行。Emoji 的最终形状取决于 Windows 字体；部分地区旗帜可能呈现为字母组合，文本编码仍保留。

**Mermaid 流程图**

在 `mermaid` 代码块中使用，例如：

````markdown
```mermaid
flowchart LR
  A[打开文件] --> B{检查}
  B -->|通过| C[阅读]
  B -->|重试| A
```
````

支持 `flowchart` / `graph`，TD/TB/BT/LR/RL 方向，常见矩形、圆角、菱形、圆形、胶囊和六边形节点，普通/虚线/粗线及带文字连接，回边、自环，单层 `subgraph` 和跨组节点连接。基础 `classDef` / `class` / `style` 支持填充、线色、文字色和线宽。

双击图表可在适应宽度与原始大小间切换；原始大小下可横向滚动。右键提供“复制代码 / 图表源码”。图表解析与布局在后台运行。

本版不承诺 Mermaid 全语法或与浏览器逐像素一致。时序图等其他类型、嵌套分组、直接连接分组容器、Mermaid 新属性语法、配置指令和未实现样式会保留源码并说明原因。Typora 的 `flow`/flowchart.js 是另一个方言，本版未实现。

单图普通处理上限为 200 节点、400 边、64 KiB 源码。超出范围后显示可阅读和复制的源码；大段回退源码同样分片，不交给浏览器。

**轻量编辑与保存**

编辑器在进入源码模式时创建，返回阅读后释放。支持中文输入法、Unicode、撤销/重做、查找替换和可选双栏预览。预览防抖更新，未改变的文字布局和图表可复用。

支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE。无改动保存、另存为以及撤销回原文后保存，保留原内容和原有换行；实际编辑后保留原编码，并使用文件既有的 LF/CRLF 风格。保存通过同目录临时文件与替换完成，遇到写入失败不会先清空原文件。磁盘文件变化时会检查冲突；关闭或导航时会处理未保存更改。

打开编辑模式的源码文件上限为 8 MiB；含 NUL 的文本保留阅读，避免控件截断。阅读文件上限为 128 MiB。图片预览会下采样到最长边 1600 像素，原图最长边超过 16384 或总计超过 64M 像素时显示占位，以限制解码开销。

**运行与诊断**

默认使用经本机验证的 Direct2D 软件绘制路径，静止时不持续刷新。高级对比可在启动前设置 `KEEPMD_RENDERER=hardware`，它只选择原生 Direct2D 后端。

开发验证参数：`--report <json>` 输出本地诊断，`--snapshot <png>` 捕获已显示的阅读区域，`--exit-after <毫秒>` 在文档就绪后自动退出，`--config <路径>` 使用独立配置，`--render-dpi <值>` 设置测试用阅读渲染目标 DPI。它们不改变系统显示设置，也不用于冒充物理跨显示器验证。

自绘正文目前没有完整的屏幕阅读器文本接口；系统控件和源码编辑器保留原生交互。实际跨显示器 DPI 切换、其他 Windows 版本和其他输入法需要对应环境继续验证。
