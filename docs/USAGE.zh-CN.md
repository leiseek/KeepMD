**KeepMD 0.5.0 使用说明**

这是一个 Windows 原生 Markdown 阅读器，附带轻量的可视化与源码编辑。解压便携包后运行 `keepmd.exe` 即可。已验证环境为 Windows 11 x64；Windows 10 和 ARM64 未纳入本次实机验证。

**两个独立程序**

便携包内的 `keepmd.exe`（阅读与编辑）和 `KeepPrompt.exe`（Markdown 提示词）是两个完全独立的程序：互不链接、互不启动、不收发窗口消息，各自保存设置。KeepMD 不再有“提示词”菜单、工具栏按钮或全局快捷键；需要提示词时直接运行 `KeepPrompt.exe`（或便携包中的“输入提示词.cmd”）。两者只共用同一套界面基础代码，构建为各自的 EXE。从 0.4.x 升级的说明见“Markdown 提示词窗口”一节末尾。

**界面与主题**

界面采用黑白灰配色，两个程序使用相同的中性色板。标题栏为 32 逻辑像素，品牌文字 13px，常规界面文字 14px；深色主题沿用相同层次。内容统计、保存状态、失败反馈与图标悬停名称保留，不常驻显示大段教学文案。

应用自己的阅读、提示词和流程图编辑窗口使用统一的自绘顶栏，不显示系统默认标题文字和关闭图标。拖动顶栏空白处移动窗口，双击最大化／还原；右侧细线按钮分别最小化、最大化／还原和关闭。可拖动窗口边缘调整尺寸，最大化不会遮挡任务栏。提示词关闭按钮仍保存并收起；阅读器关闭仍处理未保存更改。

F10 聚焦顶栏菜单，左右键切换、下键／Enter 打开，Esc 返回编辑区域；Alt+Space 或右键顶栏打开系统菜单，Alt+F4 沿用关闭行为。Win+方向键贴靠可用；自绘最大化按钮暂不提供 Windows 11 鼠标悬停的 Snap 布局弹窗。系统文件选择和消息对话框保留 Windows 外观。

阅读器的新建、打开、保存统一放在“文件”菜单，原独立操作行已移除。阅读／可视化／源码通过标题栏右侧的书本、铅笔、Markdown 图标切换，当前模式高亮，悬停显示说明；“视图”菜单也提供三个模式。可视化编辑时隐藏只作用于阅读视图的缩放和导航按钮，显示格式操作。收起工具栏后，菜单和标题栏模式图标仍可用。文档区与窗口之间保留边距，目录有独立标题。

提示词窗口为单栏可视化编辑，移除“提示词”标题及整排操作按钮；上方直接显示文字格式工具栏。“模板”菜单提供起步模板，“设置”菜单提供全局快捷键与深浅主题；“清空”位于上方格式工具栏右侧。底部只有一行：左侧显示字数、行数和保存状态，右侧为“复制全文”和“复制并收起”；按钮 28 DIP，文字 12px。过长状态使用省略号，底栏不换行。模板包括任务说明、代码审查和写作润色，追加到现有内容末尾，可用 Ctrl+Z 撤销。深浅主题覆盖标题栏、顶层菜单、工具栏、目录和状态栏；提示词的主题单独保存在 `KeepPrompt.ini`，与阅读器互不影响。按钮保留 Tab／Space 键盘操作和焦点提示。正文、源码、提示词编辑区和目录统一使用窄滑块：悬停时加宽高亮，拖动定位，点击轨道翻页，滚轮与方向键继续可用。固定预留轨道，不因出现滑块改变正文宽度。系统弹出菜单和文件对话框仍使用 Windows 外观。

提示词窗口在本次运行中保留拖动或缩放后的尺寸与位置；“设置 → 移到当前屏幕右侧”可以重新定位。最小窗口宽度为 720 逻辑像素；阅读器为 640 逻辑像素。它们随 DPI 缩放，物理跨显示器切换尚未实测。

工具栏可收起／展开：点击顶栏窗口按钮左侧的小箭头、使用 `Ctrl+Shift+T`，或从阅读器“视图 → 显示工具栏”／提示词“设置 → 显示格式工具栏”切换。收起后顶栏箭头仍保留，编辑区域自动扩展；再次操作恢复工具栏。阅读器和提示词独立记住状态，重启后恢复；阅读、源码编辑、双栏预览和提示词编辑中都可使用。提示词底部复制操作不会随格式栏隐藏。

**视觉系统**

两个程序共用一套颜色、圆角和字体规则。浅色主题为浅灰窗口底色配白色内容面板，深色主题为 RGB(27,29,34) 底色配 RGB(35,38,44) 面板；强调色用于链接、选中、焦点和按下状态，KeepMD 为蓝色，KeepPrompt 为紫色，两者使用各自的图标。正文优先使用 Segoe UI Variable，系统没有时回退 Segoe UI；代码优先使用 Cascadia Mono，回退 Consolas。阅读视图中，代码块和表格放在带细边框的圆角卡片里，代码块标注语言；一、二级标题下方有分隔线；引用使用细竖线和次要文字色；行内代码为圆角底色；链接为强调色。图片和图表无法显示时，以卡片列出名称与原因。查找、替换和快捷键输入框为扁平圆角样式，获得焦点时显示强调色边框。空白阅读页只显示 KeepMD 标记，不显示教学文字。

双栏模式下，源码编辑器与右侧预览使用相同的细滚动条。0.4.4 不再保留系统默认滚动条样式：轨道固定为 12 DIP，由 KeepMD 管理非客户区和绘制，并在控件内部更新时清除重新附加的系统滚动条样式。更换模式、主题、窗口尺寸或控件重绘后，同步自绘轨道位置与状态。仍支持轨道翻页、滚轮、键盘和长文档拖动。

**打开与阅读**

打开、拖入 Markdown 文件，或从命令行传入文件路径。支持 `.md`、`.markdown` 和独立 Mermaid 文件 `.mmd`。文件菜单提供最近文件；阅读位置、缩放、宽度和主题保存在 EXE 旁的 `keepmd.ini`，使用 UTF-8 编码。

“添加到打开方式”将 KeepMD 加入当前用户的 Markdown 候选程序列表，不修改现有默认程序。新增“设为默认打开程序…”会先完成相同注册，再打开 Windows 官方“默认应用”设置页；在页面选择 KeepMD，并为 `.md`、`.markdown`、`.mmd` 逐项确认即可。Windows 保护默认关联的 UserChoice 数据，KeepMD 不绕过该保护，也不修改其他扩展名。移动便携目录后需重新添加路径。

F11 进入全屏：窗口覆盖整个显示器，标题栏、工具栏、状态栏和页面卡片隐藏，只留文档；查找栏和目录在打开时仍显示。全屏时 Space／→／PageDown 向后翻一屏、Shift+Space／←／PageUp 向前翻一屏（每次 90% 屏高，与 PageDown 相同），Home／End 到首尾，适合演示和翻页笔；普通窗口中 ←／→ 仍横向滚动宽内容。鼠标在文档上静止 2.5 秒后指针隐藏，移动即恢复。阅读时按 Esc 退出（查找栏打开时先关闭查找栏）；编辑器把 Esc 留给自身，用 F11 退出。退出后恢复原来的位置、大小和最大化状态。全屏状态不保存，下次启动为普通窗口。

编辑时点标题栏的阅读图标可预览尚未保存的草稿，不弹出保存确认；返回原编辑模式保留内容和撤销记录。跨可视化与源码模式切换会保留内容和修改状态；关闭文件或打开其他文件时仍处理未保存更改。F6 沿用结束编辑的行为。

目录、查找与复制使用文档文本，不要求先对整篇文章完成字体排版。文件被外部修改时，阅读模式自动刷新；编辑模式保留当前内容并提示磁盘变化。正文中的本地 Markdown 链接在应用内导航；点击 HTTP(S) 链接交给系统默认浏览器。

**Markdown 范围**

已实现标题、段落、粗体、斜体、删除线、行内代码、引用、嵌套列表、围栏与缩进代码块、链接和引用式链接、常见 GFM 表格及只读任务列表。本地 PNG/JPEG/BMP 等由 Windows WIC 解码；无法处理的图片显示占位和原因。表格可横向阅读，复制表格文本时使用制表符分隔单元格。

阅读不会改写 Markdown。正文复制为可读文本；源码模式提供完整原文。支持独立的 HTML `<img>`，以及表格之外的行内 `<img>`（按图片块显示，保留前后文字）。例如：

```html
<img src="images/logo.png" alt="Logo" width="400">
```

`src` 相对于当前 Markdown 文件所在目录解析，支持中文、空格、URL 百分号编码和 HTML 属性实体。标签／属性名不区分大小写，支持多行、单／双引号及无引号属性。`width`／`height` 接受 1–16384 的正整数逻辑像素，随阅读缩放；只指定一项时保持图片比例，同时指定时采用指定比例，超出可用宽度时整体缩小。非法尺寸回退到自然尺寸，单个标签解析上限 16 Ki 字符。图片仍使用原有 WIC 解码预算，不增加浏览器依赖。

代码块与行内代码中的标签仍显示原文。下文“README HTML”子集之外的 HTML 及表格单元格内图片不作排版，保留原文；`style`／事件属性不执行。HTTP(S) 图片默认不加载、不联网：未缓存的网络图片显示占位卡片，点击图片不会触发下载或打开浏览器。使用工具栏最右侧的“网络图片”图标（或“视图 → 加载本文网络图片”）开启当前 Markdown 的全部网络图片加载，屏幕外的图片也会排队加载；无需逐张点击或弹窗确认。重复 URL 只下载一次，两个窗口同时打开相同 URL 也会合并下载。再次点击开关停止尚未完成的下载，已加载及已缓存的图片继续显示；切换到其他文档时下载开关默认关闭，编辑预览及同文件重新加载保留开关状态。失败可关闭后重新开启重试。网络共享与 `data:` 图片仍不加载。公式、脚注、Wiki 链接、完整 HTML/CSS、动态图和远程图片自动下载不属于本版范围。

网络图片缓存保存在 `%LOCALAPPDATA%\KeepMD\Cache\Images`，按规范化 URL 标识；不同路径、查询参数分别缓存，大小写不同的主机名、默认端口和片段不产生重复条目。缓存跨文档、重启复用，即使网络开关关闭或离线也能直接显示；仅在缓存缺失、损坏或被淘汰后重新开启下载才会再次请求。缓存上限为 256 MiB／1024 个条目，优先淘汰最久未使用的内容；写入采用原子替换，读取校验完整性，失败响应和不可解码内容不会入缓存。缓存写入失败不影响本次显示。可用 `--image-cache <目录>` 指定缓存位置。

单图下载上限为 8 MiB，总请求时间最多 15 秒，并发下载最多两个；下载在后台进行，切换文档、关闭窗口或关闭开关会取消请求。TLS 证书按系统规则验证，不自动发送登录凭据、Cookie 或文档来源。解码沿用本地图片限制（最长边 16384、总计 64M 像素，预览下采样至 1600），支持现有 WIC 图片格式及下文的 SVG 子集；动图不播放，只显示第一帧。缓存不会主动联网检查同 URL 内容是否更新。

**SVG 与图片失败原因**

本地和网络 SVG 由 Windows 自带的 Direct2D SVG 支持绘制，不使用浏览器组件。Direct2D 只支持 SVG 的一个子集：`path`、`rect`、`circle`、`ellipse`、`line`、`polyline`、`polygon`、`g`、`use`、渐变和裁剪路径等图形元素可以显示，适合纯图形 Logo 和图标。**文字不受支持**，而 Direct2D 遇到不支持的内容会静默跳过、只画剩下的部分；为避免把 `shields.io` 这类靠文字表达含义的徽章画成没有字的色块，含 `<text>`／`<tspan>`／`<textPath>`、`<style>` 样式表、`<mask>`、`<pattern>`、`<symbol>` 或 `<foreignObject>` 的 SVG 显示占位卡片（替代文字＋“SVG 含文字、样式表或遮罩等暂不支持的内容”）。滤镜、动画和外部引用被忽略。

SVG 尺寸按浏览器规则确定：使用根元素的 `width`／`height`，缺少时取 `viewBox`，都没有时为 300×150；只给一边时按 `viewBox` 比例推算。绘制分辨率为显示尺寸的两倍（本地图片的 HTML `width`／`height` 计入显示尺寸），最长边不超过 1600 像素，因此在 200% 缩放的屏幕上保持清晰；阅读缩放超过这一倍数时会变软。SVG 源文件上限 4 MiB。压缩的 `.svgz` 不支持。

图片无法显示时，占位卡片区分原因：找不到文件（显示文件名）、文件存在但无法读取（权限、被占用或路径是目录）、格式无法解码、超过预览上限，以及上述 SVG 子集外的内容。

**README HTML**

README 常见的 HTML 子集转换为原生块：`h1`–`h6`、`p`、`div`、`center`、`blockquote`、`ul`／`ol`／`li`（含 `start`）、`hr`、`details`／`summary`（内容始终展开，摘要前显示 ▾）、`picture`（使用其中的 `<img>`）及 `section` 等语义容器；行内支持 `a`、`b`／`strong`、`i`／`em`、`u`／`ins`、`s`／`del`、`code`／`kbd`／`samp`、`br`、`span`、`sub`／`sup` 等。注释隐藏，`<a name>` 锚点不显示。表格单元格内的行内标签（如 `<br>`、`<b>`）同样生效，单元格内图片仍显示原文。

`align="center|right|left"` 与 `<center>` 使文字、标题和图片居中或靠右；在单独 HTML 块里打开的 `div`／`center`／`details` 等容器会让后续 Markdown 保持该对齐，直到对应结束标签。空白按 HTML 规则折叠，实体解码，复制得到显示后的文字。

图片 `src` 和链接以 `/` 开头时，与 GitHub 一样按仓库根目录解析：从当前文件所在目录向上找到含 `.git` 的目录，找不到时使用当前目录，例如 `/public/imgs/words.png`、`/docs/README.es.md`。

一个 HTML 块只有全部标签都在子集内才转换；含表格、`pre`、`script`、表单、未知标签、无 `src` 的图片、未闭合注释或格式错误标签的块仍显示原文，并保持 `div`／`center` 的嵌套计数。行内出现子集外的标签时，该处保留原文。CSS、`style`、事件属性、`img` 的 `align` 浮动和多图并排不实现；单个 HTML 块上限 128 Ki 字符、嵌套 64 层。

超长段落和超长代码行会拆成有限大小的显示片段。分片处可能提前换行，复制内容保持连续，不向原文件插入换行；横跨分片处的查找命中两侧都会高亮。Emoji 的最终形状取决于 Windows 字体；部分地区旗帜可能呈现为字母组合，文本编码仍保留。

**Mermaid 流程图**

在 `mermaid` 代码块中使用，例如：

````markdown
```mermaid
flowchart LR
  A[打开文件] --> B{检查}
  B -->|通过| C[阅读]
  B -->|重试| A
```
````

支持 `flowchart` / `graph`，TD/TB/BT/LR/RL 方向，常见矩形、圆角、菱形、圆形、胶囊和六边形节点，普通/虚线/粗线及带文字连接，回边、自环，单层 `subgraph` 和跨组节点连接。基础 `classDef` / `class` / `style` 支持填充、线色、文字色和线宽。

双击图表可在适应宽度与原始大小间切换；原始大小下可横向滚动。右键提供“复制代码 / 图表源码”。图表解析与布局在后台运行。

本版不承诺 Mermaid 全语法或与浏览器逐像素一致。时序图等其他类型、嵌套分组、直接连接分组容器、Mermaid 新属性语法、配置指令和未实现样式会保留源码并说明原因。Typora 的 `flow`/flowchart.js 是另一个方言，本版未实现。

单图普通处理上限为 200 节点、400 边、64 KiB 源码。超出范围后显示可阅读和复制的源码；大段回退源码同样分片，不交给浏览器。

**轻量编辑与保存**

编辑器按需创建。标题栏阅读预览保留编辑会话；F6 结束编辑或打开其他文档时释放。支持中文输入法、Unicode、撤销/重做、查找替换和可选双栏预览。预览防抖更新，未改变的文字布局和图表可复用。

**可视化编辑**

新建文档（Ctrl+N）直接进入可视化编辑：标题、粗体、斜体、列表、引用、行内代码、代码块和流程图在输入时呈现样式，常用 Markdown 标记完成输入后隐藏，保存的仍是原样的 Markdown 源码。可视化模式下工具栏显示格式按钮（标题 1、标题 2、加粗、斜体、列表、编号、引用、代码、流程图），Ctrl+B／Ctrl+I 同样可用；正文居中排在阅读宽度内。表格以 Markdown 源码行显示并可直接编辑，暂不提供单元格网格。

F6 进入编辑时沿用上次使用的模式，默认为可视化；Ctrl+E、标题栏可视化／源码图标或“视图 → 可视化 / 源码编辑”在两种模式间切换，切换不改动文字，保存状态保持不变；两种编辑控件之间切换会重建撤销历史，原模式与阅读预览之间切换则保留撤销历史。该偏好保存在 `keepmd.ini` 的 `Visual=`（1 为可视化，0 为源码）。双栏预览只在源码模式提供；可视化模式中 Ctrl+F 查找可用，Ctrl+H 替换会先切换到源码模式。连续输入合并为一步撤销，停顿约 1 秒或执行格式、粘贴、回车等操作后开始新的一步。

每次停止输入后，可视化编辑会重新排版整篇文档：本机实测约 10 万字符需 60 ms、20 万字符约 110 ms。因此超过约 26 万 UTF-16 字符（256 Ki）的文档进入编辑时使用源码模式，并在状态栏说明原因，Ctrl+E 也不会切换到可视化。含 U+FFFC（对象占位符）的文件保留阅读模式：Windows 编辑控件会把该字符替换为空格，继续编辑会悄悄改变文件。

支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE。无改动保存、另存为以及撤销回原文后保存，保留原内容和原有换行；实际编辑后保留原编码，并使用文件既有的 LF/CRLF 风格。保存通过同目录临时文件与替换完成，遇到写入失败不会先清空原文件。磁盘文件变化时会检查冲突；关闭或导航时会处理未保存更改。

打开编辑模式的源码文件上限为 8 MiB；含 NUL 的文本保留阅读，避免控件截断。阅读文件上限为 128 MiB。图片预览会下采样到最长边 1600 像素，原图最长边超过 16384 或总计超过 64M 像素时显示占位，以限制解码开销。提示词由独立的 `KeepPrompt.exe` 提供，KeepMD 不启动也不关闭它。

**Markdown 提示词窗口**

运行 `KeepPrompt.exe`（或“输入提示词.cmd”）显示提示词窗口；`KeepPrompt.exe --resident` 静默启动并常驻托盘，`--show` 立即显示窗口。启动后在任何应用中按 `Ctrl+Alt+Space` 唤起。第一次显示才加载可视化编辑控件。直接在排版后的内容中输入，不需要源码模式，也没有预览双栏。复制和保存输出 Markdown。KeepMD 阅读器不提供、也不启动提示词窗口。

| 提示词窗口操作 | 快捷键 / 入口 |
| --- | --- |
| 从任何应用唤起 | Ctrl+Alt+Space，可自定义 |
| 复制完整源码并收起 | Ctrl+Enter、再次按全局快捷键、按钮“复制并收起” |
| 仅收起 | Esc；设置展开时先关闭设置，不更改剪贴板（0.4.x 中 Esc 也会复制） |
| 复制全文并保持窗口 | Ctrl+Shift+C 或“复制全文” |
| 加粗 / 斜体 | Ctrl+B / Ctrl+I 或格式按钮 |
| 正文 / 标题 / 列表 / 编号 / 引用 / 行内代码 | 格式工具栏 |
| 插入／修改流程图 | “流程图”按钮，或双击已有图形 |
| 导出为 .md | Ctrl+S 或文件菜单 |
| 载入 Markdown / 旧 Prompt Flow JSON | 文件菜单 |
| 清空（可 Ctrl+Z 撤销） | “清空” |
| 选中、撤销、重做 | 原生编辑器 Ctrl+A/C/X/V/Z/Y |
| 切换控件焦点 | Ctrl+Tab / Ctrl+Shift+Tab；正文 Tab 用于输入缩进 |
| 仅保存并收起，不复制 | 窗口右上角关闭按钮 |

标题、加粗、斜体、删除线、列表、引用和代码会直接呈现样式，常用 Markdown 标记在完成输入后隐藏。选中文字后点格式按钮，或使用 Ctrl+B/I；未选择文字时会插入已选中的“文字”／“代码”占位内容，输入即可替换。标题末尾回车开始正文；列表回车继续下一项，空项目再次回车退出列表。撤销／重做包括文字、格式与流程图；连续输入合并为一步，停顿约 1 秒或执行格式、粘贴、回车等操作后开始新的一步。最多保留 64 步，并受 8 MiB 历史内存预算约束。

流程图以内嵌原生图片显示，双击或点格式栏“流程图”打开专门的 Mermaid 编辑框；应用后回到同一个可视化文档。选中图形后按 Delete 可删除，Ctrl+Z 可恢复。最多显示 16 张内嵌流程图，单图仍限制 200 节点／400 边／64 KiB；后续图表及尚未闭合的围栏保留为代码。大图在编辑区内缩放，原阅读器支持更完整的图表查看操作。

可视化提示词目前以常用文字结构和流程图为重点。表格以 Markdown 源码行显示，暂不提供单元格网格编辑；图片暂不提供内嵌图片编辑，复杂嵌套结构没有完整富文本排版能力；其 Markdown 保留，复制导出不丢弃这些结构。HTML 不执行，链接不自动打开。

复制保留缩进、空白行和末尾换行，Markdown 使用 LF 换行；工具不会自动提交或模拟粘贴。收起后尝试返回唤起前的窗口，再按 Ctrl+V 粘贴。Windows 拒绝前台切换或原窗口已关闭时，可自行切回目标窗口。中文输入法正在组词时，Esc 优先取消组词，不会收起窗口。输入上限为 1 Mi UTF-16 单元；状态栏字符数采用 UTF-16 单元统计。

通过“设置 → 设置全局快捷键”展开输入行，输入 `Ctrl+Alt+Space`、`Ctrl+Shift+J` 等组合并点“应用”，或选择“双击左 Ctrl”。双 Ctrl 的两次松开间隔不超过 350 ms；原 Prompt Flow 仍运行时必须先退出旧工具，避免同时响应。组合快捷键注册失败会给出提示并保留旧键。默认键被占用时，运行 `KeepPrompt.exe` 会显示窗口并展开快捷键设置，可直接更改。

关闭按钮保存草稿并收起窗口，KeepPrompt 继续在后台等待快捷键；“设置 → 常驻系统托盘”开启后同时显示托盘图标。托盘菜单或文件菜单“退出 KeepPrompt”才结束进程。`--resident` 启用常驻并静默启动；`--show` 立即显示窗口。再次运行 `KeepPrompt.exe` 会唤起同一配置的现有实例，不会启动第二个。

登录 Windows 时启动默认关闭，需在“设置 → 登录 Windows 时启动”中显式开启；它只写当前用户、该配置专属的启动项。关闭常驻会同时关闭该配置的登录启动。便携目录移动前请关闭登录启动，移动后重新启用，以更新路径。

设置保存在 `KeepPrompt.exe` 同目录的 `KeepPrompt.ini`，草稿为 `KeepPrompt.draft.md`，均为本地明文。`--config D:\MyNotes\prompt.ini` 使用指定的设置文件，草稿放在同目录的 `prompt.draft.md`。KeepPrompt 不读写 KeepMD 的 `keepmd.ini`。请把便携程序放在可写目录，或指定可写的配置位置。

从 0.4.x 升级时，旧版本把提示词保存在 `keepmd.prompt.ini` 与 `keepmd.prompt.md`。`KeepPrompt.exe` 旁还没有 `KeepPrompt.ini`／`KeepPrompt.draft.md`、而存在这两个旧文件时，KeepPrompt 直接沿用旧文件，草稿、快捷键和其他设置保持不变。0.4.6 注册的登录启动项以 `--config keepmd.ini` 启动，现在同样沿用旁边的旧提示词文件，不会把 `keepmd.ini` 当作提示词设置改写，“登录 Windows 时启动”也能识别并关闭这个旧启动项。0.4.5 及更早版本的启动项运行 `keepmd.exe --resident`；KeepMD 已没有后台服务，这条命令现在直接退出、不打开窗口，请在 KeepPrompt 中重新开启登录启动。解压到新目录时，把旧目录中的 `keepmd.prompt.ini` 和 `keepmd.prompt.md` 复制到 `KeepPrompt.exe` 旁即可继续使用。

草稿在停止输入约 800 ms 后保存，复制收起或退出前再次保存。剪贴板被占用、文件被锁定或写入失败时保留输入并说明原因；草稿在外部被改动后停止覆盖，可“导出 Markdown”保存当前输入，再退出重启。若退出时仍不能保存，可选择导出、放弃未保存输入或取消。损坏或包含保留控制字符 NUL / U+FFFC 的磁盘草稿会被保留，修复后重启即可重新载入。

导入旧配置时，在文件菜单选择“导入 Prompt Flow 配置”，默认定位到 `%APPDATA%\PromptFlow\PromptFlow\config`。导入 `config.json` 可恢复草稿、快捷键、置顶和透明度；不会改动旧文件或自动继承登录启动。替换已有草稿前会确认，替换可撤销。图片和复杂格式的原始 Markdown 会保留；如需查看完整阅读效果，可导出 .md 后用阅读器打开。

**运行与诊断**

默认使用经本机验证的 Direct2D 软件绘制路径，静止时不持续刷新。高级对比可在启动前设置 `KEEPMD_RENDERER=hardware`，它只选择原生 Direct2D 后端。

开发验证参数：`--report <json>` 输出本地诊断，`--snapshot <png>` 捕获已显示的阅读区域，`--exit-after <毫秒>` 在文档就绪后自动退出，`--config <路径>` 使用独立配置，`--render-dpi <值>` 设置测试用阅读渲染目标 DPI。它们不改变系统显示设置，也不用于冒充物理跨显示器验证。

自绘正文目前没有完整的屏幕阅读器文本接口；系统控件和源码编辑器保留原生交互。实际跨显示器 DPI 切换、其他 Windows 版本和其他输入法需要对应环境继续验证。
