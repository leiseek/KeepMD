**0.6.0 的变化与验证**

- **LaTeX 公式。** 阅读视图用固定版本的 MicroTeX 排版 `$…$` 与 `$$…$$`，由 KeepMD 自己的 Direct2D 后端绘制，字体嵌入 EXE，不联网、不启动浏览器。真实窗口中 15 个公式排版、1 个无法恢复的公式按源码显示；4 组检查通过：查找命中公式源码、复制得到原样 LaTeX、主题切换与缩放后重新排版。核心检查覆盖离屏绘制的墨迹位于排版框内、绘制后恢复调用方变换、未知命令标红、无法恢复的错误退回源码、“价格 $5 和 $6”与“售价 $ 100 和 $ 200”不被识别为公式、超长段落切块不切开公式，以及替代符号可见。见 [公式验证](../bench/results/math-e2e.json)。
- **公式字体许可。** 只嵌入许可明确的 20 个字体；上游 10 个许可或来源不明的字体不随附，其中的 « » ‰ € µ 等符号改用 Windows 自带字体绘制，`\android` 不显示。逐个字体的依据见第三方说明。
- **KeepPrompt 托盘与按键。** 运行期间始终显示托盘图标；最小化与关闭都保存并收起到托盘；Esc 不再收起窗口，只关闭设置面板；进程只能从托盘菜单退出。提示词全量套件 17 项与视觉系统套件按新行为断言（Esc 后窗口保留、最小化后托盘图标存在、未开启常驻也有托盘图标）。
- **启动开销。** `keepmd.exe` 静态链接 MicroTeX 与公式字体后体积增大，见下文；在不含公式的文档上，MicroTeX 只在首次遇到公式时初始化，其全局表在启动时约多占 0.3 MiB 私有内存。

**0.5.0 引入的能力（本版回归）**

- **两个独立程序。** KeepMD 与 KeepPrompt 只共用界面基础库，互不链接、启动或发送消息，各自保存设置。8 组检查通过：KeepMD 单独运行且没有提示词入口，旧的 `--prompt` 参数不再启动其他程序；KeepPrompt 隐藏常驻并转发第二次启动；关闭 KeepMD 不影响 KeepPrompt；0.4.x 便携目录与登录启动项升级后原位沿用提示词草稿，0.4.5 的 `keepmd.exe --resident` 启动项静默退出。见 [独立性验证](../bench/results/prompt-process-e2e.json)。
- **README HTML 子集与 HTML 图片。** 常见 README HTML 块转为原生块，子集外的块保留原文。17 组检查覆盖 `<img>` 宽高／缩放／多行属性、中文与空格路径、行内图片、双栏预览、居中与跨块对齐、仓库根相对路径、代码／表格／缺失／远程回退及源码无改动保存；Ghidra README 的本地 Logo 实测宽 400 像素；TypeWords README 头部的 HTML 原生显示、根相对路径截图载入，读取前后两个外部仓库的文件哈希一致。截图仅作本地验证，不将外部项目素材打入制品。见 [HTML 验证](../bench/results/html-images-e2e.json)。
- **KeepMD 文档可视化编辑。** 8 组真实键盘检查通过：打开即为可视化编辑且 Markdown 原样保留，Unicode 输入与 Ctrl+B，保存未触碰的表格和流程图，Ctrl+E 双向切换并记住模式，连续输入合并为一步撤销，新建文档进入可视化，含 U+FFFC 的文件保留阅读，超出可视化上限的文件使用源码编辑并说明原因。见 [文档可视化编辑验证](../bench/results/visual-document-e2e.json)。

- **全屏阅读。** 6 组真实键盘／指针检查通过：F11 覆盖显示器并隐藏标题栏、工具栏、状态栏和页面卡片；Space／方向键／PageDown 等翻页位移与 PageDown 一致；指针静止 2.5 秒隐藏；查找栏与两次 Esc；最大化窗口往返；编辑器全屏中 Esc 留给编辑器。见 [全屏验证](../bench/results/fullscreen-e2e.json)。

**启动与内存**

S100 为约 100 KiB 的中英混排 Markdown。每次新建进程、文件缓存温热，重复 30 次。正式口径从启动器的 QPC 采样到正文首屏绘制提交，包含进程创建，不包括物理显示器扫描呈现。

| 指标 | 实测 | v0.5.0 |
| --- | --- | --- |
| 启动到正文提交 p50 | 106.24 ms | 112.95 ms |
| 启动到正文提交 p95 | 128.39 ms | 119.35 ms |
| 程序内部首屏 p95（不含进程创建） | 110.10 ms | 110.16 ms |
| Private Bytes 中位数 / 最大值 | 14.79 / 15.42 MiB | 16.42 / 16.81 MiB |
| Working Set 中位数 | 33.67 MiB | — |
| 50 MiB 压力文件首屏 p95（3 次初筛） | 778.80 ms | 867.21 ms |
| 50 MiB 压力文件 Private Bytes 中位数 | 414.59 MiB | 416.09 MiB |

与 v0.5.0 相比：S100 启动 p50 快 6.7 ms，p95 慢 9.0 ms，Private Bytes 中位数少 1.6 MiB，50 MiB 首屏 p95 快 88.4 ms；同期 `keepmd.exe` 从 991,232 字节增至 2,795,008 字节（加入了 MicroTeX 公式排版代码与 20 个嵌入字体）。差异的具体来源未逐项定位，不将其归因于某一项改动。50 MiB 只有 3 次初筛，波动较大。验收文档的 S100 温热首屏目标为 p95 ≤ 100 ms，按程序内首屏（110.10 ms）和启动到提交（128.39 ms）两种口径均未达到；v0.5.0 的程序内首屏 p95 为 110.16 ms，同样未达到。稳态内存远低于 40 MiB 的目标。

50 MiB 文件的语义文本与块模型仍随文件大小增长，不能把小文档内存数字套到所有文件。正式数值见 [S100 原始结果](../bench/results/software-s100.json)、[50 MiB 结果](../bench/results/software-l50.json)。

本机：Intel(R) Core(TM) i5-14600KF，约 31.8 GiB 可见内存，Windows 10.0.26300，默认软件绘制。完整驱动与环境见 [environment.json](../bench/results/environment.json)。没有关闭杀毒以美化数据。30 次的 p95 只作本机工程验证，不代表稳定的跨机器保证；历史运行存在系统状态波动，均保留而非只展示最佳值。冷缓存首屏没有可靠实测结果。

**依赖与交付边界**

**默认打开方式**：文件菜单的“设为默认打开程序…”注册当前用户的 KeepMD 后打开 Windows 官方默认应用设置页，由用户确认 `.md`、`.markdown` 和 `.mmd`。程序不直接改写受 UserChoice 保护的默认值。

PE 导入表只包含 Windows 系统 DLL，没有 Electron、WebView、Chromium、Qt、Node 或额外 MSVC 运行时 DLL。源码编辑器通过系统 `Msftedit.dll` 按需创建；SVG 使用系统 Direct2D。图表失败时显示原始代码，不启动隐藏浏览器。网络图片只在用户打开当前文档的开关后通过系统 WinHTTP 下载。[导入表检查](../bench/results/dependencies.json)

Mermaid 支持明确的 flowchart/graph 子集：200 节点、400 边、64 KiB 源码；其他语法保留源码和诊断。完整 Mermaid、公式、任意 HTML/CSS、SVG 文字与全特性没有被宣称完成；PDF／Word 导出与多标签不在路线内。物理跨显示器切换、Windows 10、ARM64 和完整正文屏幕阅读器支持未验证或未实现。便携程序未做代码签名。

便携包内有使用说明、示例、许可证、此报告、原始结果和 SHA256SUMS。源码包提供完整构建与测试脚本。正式交付摘要见 [release-summary.json](../bench/results/release-summary.json)。
