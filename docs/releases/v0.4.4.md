KeepMD 0.4.4 将原生 Markdown 阅读、Mermaid 流程图和全局唤起的提示词编辑整合到一个 Windows 便携程序中。应用不依赖 Electron、Tauri、WebView 或浏览器运行时。

**下载与运行**

- `KeepMD-0.4.4-windows-x64.zip`：Windows x64 便携版。解压到可写目录后运行 `keepmd.exe`。
- `KeepMD-0.4.4-source.zip`：与本 Release 标签对应的完整源码、第三方许可证、构建和测试脚本。
- `KeepMD-0.4.4-SHA256SUMS.txt`：以上两个 ZIP 的 SHA-256；便携包内另有逐文件校验清单。
- `KeepMD-0.4.4-VALIDATION.zh-CN.md`：实测报告及验证范围，便携包内也有对应报告。

**功能**

- Windows 原生 Markdown 阅读和预览，支持常用 Markdown、表格、本地图片及 Mermaid `flowchart` / `graph` 子集。
- `Ctrl+Alt+Space` 唤起可视化提示词窗口，复制和保存为 Markdown；`Ctrl+Enter` 复制并收起。
- 原生图标工具栏、自绘顶栏和细滚动条；`Ctrl+Shift+T` 收起／展开工具栏。
- 轻量源码编辑、搜索、目录、最近文件、草稿保存、旧 Prompt Flow 配置导入及可选托盘常驻。
- 0.4.4 增加“文件 → 设为默认打开程序…”：注册 `.md`、`.markdown`、`.mmd` 后打开 Windows 默认应用设置页，需要用户在系统中确认。

**验证与已知限制**

146 项核心检查通过；打包后重新校验全部文件，并实际运行解压的程序，检查阅读、提示词复制和保存。历史性能记录绑定到本次发布的 EXE SHA-256，具体环境和数字见附件中的验证报告。

提示词可视化编辑的中文 IME 提交及 Esc 组词路径在 0.4.4 本轮未通过验证：原始结果记录其保持英文转换状态，不能将普通源码编辑的输入法成功测试等同于提示词输入法通过。该限制在报告中明确保留。

仅实测 Windows 11 x64，未验证 Windows 10、ARM64 或物理跨显示器 DPI 切换。Mermaid 为受限子集；可视化提示词编辑不提供完整表格网格与内嵌图片编辑。自绘最大化按钮不提供 Windows 11 悬停 Snap 布局弹窗，可使用 Win+方向键。程序未做代码签名。
