KeepMD 0.4.5 修复 Markdown 中 HTML `<img>` 只能显示源码的问题，使用现有 Windows WIC／Direct2D 原生图片管线，没有新增运行时依赖。

- 支持本地相对路径、中文／空格路径、HTML 属性实体，以及单／双引号、多行和大小写混合的标签。
- 支持 `width`／`height`，单边尺寸保持比例，双边尺寸按指定比例绘制，随阅读缩放并适应可用宽度。
- 阅读和双栏预览均可显示；代码示例保留原文，源码保存保留原始字节。
- 实测 Ghidra README 顶部的 PNG Logo 按 `width="400"` 显示，测试前后原 README 和图片哈希不变。

下载 `KeepMD-0.4.5-windows-x64.zip`，解压后运行 `keepmd.exe`。源码 ZIP 对应此 Release 标签；SHA256SUMS 提供两个 ZIP 的校验值。验证报告和原始数据随包提供。

这是明确范围的 `<img>` 支持，不是完整 HTML 引擎。容器 HTML、表格单元格内图片仍保留原文；HTTP／网络共享／内嵌数据图片不自动加载，SVG 暂不渲染。因此该 README 的远程 SVG 徽章仍不显示。

仅实测 Windows 11 x64。Mermaid 仍为 flowchart/graph 子集；提示词可视化编辑的中文 IME 提交及 Esc 组词路径尚未通过验证，普通源码编辑器的成功验证不能替代它。完整限制与性能口径见随附验证报告。程序未做代码签名。

171 项核心检查、12 组图片专项及独立阅读／编辑／压力／UI 回归通过。提示词完整集成脚本本轮出现焦点／撤销等待超时，一轮旧配置导入自动化中进程以 `0xC000041D` 退出，原因尚未定位；这些路径不列为本版完整验证通过。独立可视化编辑、复制保存和界面专项通过。报告保留这一区别及重跑记录。
