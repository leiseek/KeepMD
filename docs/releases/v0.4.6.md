KeepMD 0.4.6 将提示词管理从阅读器进程拆分为独立的 `KeepPrompt.exe`。

- `KeepPrompt.exe --resident` 可独立驻留托盘并注册全局快捷键。
- `KeepMD.exe --prompt` 作为轻量 broker 启动或唤起同目录 KeepPrompt，然后退出；阅读器关闭不会终止提示词进程。
- KeepPrompt 保留可视化 Markdown 编辑、草稿保存、复制、快捷键设置、托盘和旧 Prompt Flow 配置导入。
- 便携包同时包含 `keepmd.exe` 与 `KeepPrompt.exe`，二者共享同一配置目录和原生核心，不依赖 WebView、Electron 或 Tauri。
- 0.4.5 的本地 HTML `<img>` 支持继续保留；Ghidra README Logo 及 400 宽度专项已验证。
- UI 进一步收紧：标题栏 38 DIP、菜单字体 12/13 DIP、阅读工具按钮 32×30 DIP、提示词格式按钮 34×32 DIP、图标 17 DIP；点击区域和键盘操作保持可用。

独立进程专项验证了常驻隐藏、KeepMD broker 唤起、编辑自动保存／复制、关闭 KeepMD 后 KeepPrompt 继续工作及 KeepPrompt 独立退出。旧版同进程全量提示词自动化仍有焦点／撤销等待和一轮旧配置导入异常，未将其列为本版完整通过。提示词可视化编辑中文 IME 提交及 Esc 组词路径尚未通过完整验证。

下载 `KeepMD-0.4.6-windows-x64.zip`，解压后可直接运行 `KeepPrompt.exe`。源码 ZIP 与 `v0.4.6` 标签对应，校验值见 SHA256SUMS。
