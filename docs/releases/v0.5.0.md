KeepMD 0.5.0 把阅读器与提示词工具拆成两个完全独立的程序，并为 KeepMD 加入文档可视化编辑、README HTML、网络图片、SVG 与全屏阅读。

- **两个独立程序。** `keepmd.exe` 与 `KeepPrompt.exe` 互不链接、启动或发送消息，各自保存设置、使用各自的图标。KeepMD 不再有“提示词”菜单、按钮或全局快捷键，需要时直接运行 `KeepPrompt.exe`。从 0.4.x 升级时，提示词草稿、设置与登录启动项原位沿用；0.4.5 的 `keepmd.exe --resident` 启动项现在直接退出，请在 KeepPrompt 中重新开启登录启动。KeepPrompt 中 Esc 改为只收起窗口，不再复制；复制并收起用 Ctrl+Enter 或再次按全局快捷键。
- **文档可视化编辑。** 新建文档直接进入可视化编辑，Ctrl+E 在可视化与源码之间切换并记住选择，Markdown 原样往返；超大文件和含 U+FFFC 的文件使用源码编辑或保留阅读，并说明原因。
- **README HTML。** 常见 README 的 HTML 子集（标题、段落、链接、强调、列表、引用、分隔线、`details`／`summary`、`picture`、`align`／`<center>`）原生显示，子集外的块保留原文；以 `/` 开头的图片和链接按仓库根目录解析。不执行 CSS、`style` 或脚本。
- **网络图片。** 默认不联网。工具栏最右侧的开关加载当前文档的全部 HTTP(S) 图片，结果缓存在本机，跨文档、重启复用。
- **图片与 SVG。** 无法显示的图片说明原因：找不到文件、无法读取、无法解码或超过上限。纯图形 SVG 由 Windows 自带的 Direct2D 绘制；Direct2D 不支持文字，含文字、样式表或遮罩的 SVG（例如 shields.io 徽章）显示占位与原因，而不是画成缺字的色块。
- **全屏阅读。** F11 进入全屏，只留文档；Space、方向键、PageDown／PageUp 按屏翻页，适合演示和翻页笔；指针静止 2.5 秒隐藏。阅读时按 Esc、编辑时按 F11 退出，恢复原窗口位置与最大化状态。
- **视觉系统。** 两个程序统一黑白灰浅／深配色与 32 DIP 紧凑标题栏，阅读／可视化／源码三种模式改为标题栏图标。
- 查找时，横跨超长段落内部切分处的命中两侧都会高亮。

验证：233 项核心检查与全部 GUI 套件在本版两个 EXE 上通过，详见验证报告。提示词可视化编辑的中文输入法提交已通过真实输入验证，Esc 取消组词的路径已执行但没有单独断言，不宣称完整通过。测试桌面上另一程序占用了默认快捷键 Ctrl+Alt+Space，真实全局快捷键唤起改用 Ctrl+Alt+Shift+F9 完成。S100 温热首屏 p95 约 110–119 ms，未达到 100 ms 的验收目标（0.4.6 同样未达到）。

下载 `KeepMD-0.5.0-windows-x64.zip`，解压后运行 `keepmd.exe` 或 `KeepPrompt.exe`。源码 ZIP 与 `v0.5.0` 标签对应，校验值见 SHA256SUMS。
