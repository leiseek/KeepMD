KeepMD 0.6.0 在阅读视图中原生排版 LaTeX 公式；KeepPrompt 修正提示词窗口的收起与退出方式：窗口随时可找回，退出只由托盘菜单完成。

- **LaTeX 公式。** `$…$` 行内公式与 `$$…$$` 独立公式由内置的 MicroTeX 排版、Direct2D 绘制，使用嵌入 EXE 的 Computer Modern 字体，不联网、不需要安装 TeX，也不启动浏览器。行内公式随文字换行，含分数的段落统一加大行距；单独成段的独立公式居中。公式跟随深浅主题与引用的灰色。查找、全选和复制得到的仍是 LaTeX 源码，阅读不改写文件。识别规则与 Pandoc、GitHub 一致，“价格 $5 和 $6”“售价 $ 100 和 $ 200”保持原文。不认识的命令标红显示，括号不匹配等无法恢复的错误使整条公式按源码显示。不支持 `\def`、`\tag` 编号与完整 LaTeX 宏包；可视化与源码编辑中公式显示为源码。€、µ、‰ 等少数符号来自许可不明、未随附的字体，改用 Windows 自带字体绘制，`\android` 不显示。`keepmd.exe` 因排版代码与 20 个嵌入字体从约 968 KiB 增至约 2.7 MiB。
- **托盘图标常驻。** KeepPrompt 运行期间始终显示托盘图标，不再依赖“常驻系统托盘”开关。原来在默认设置下，窗口一旦收起或最小化就没有任何入口可以找回它，只能靠全局快捷键。图标在资源管理器重启后自动恢复；如果图标创建失败，窗口保持显示并给出说明，不会把窗口藏在找不到的地方。
- **最小化收起到托盘。** 点最小化按钮或按 Win+↓ 会先保存草稿，再把窗口收到托盘；单击托盘图标或按全局快捷键重新打开。提示词窗口是工具窗口，本来就没有任务栏按钮，所以最小化不再把它留在一个无法操作的状态。
- **Esc 不再收起窗口。** 设置面板展开时，Esc 只关闭设置面板；其他时候 Esc 不再收起窗口，也不会复制内容。中文输入法正在组词时，Esc 仍然用于取消这次组词。收起窗口请用标题栏关闭按钮或 Ctrl+Enter。
- **只能从托盘退出。** 窗口的“文件”菜单不再有“退出 KeepPrompt”，托盘右键菜单是唯一的退出入口，避免误关正在输入的草稿。窗口的关闭按钮和最小化一样，只保存并收起，不结束进程。
- **“常驻系统托盘”开关移除。** 托盘图标已经常驻，这个开关没有意义。以前关闭它会顺带移除登录启动项，现在登录启动只由“登录 Windows 时启动”单独控制。

验证：核心检查与全部 GUI 套件在本版两个 EXE 上通过。提示词套件新增“Esc 后窗口仍保留”“最小化收起到托盘且托盘图标存在”“未开启常驻也有托盘图标”三项检查。中文输入法提交仍通过真实输入验证；Esc 取消组词的按键路径已执行，但套件没有单独断言“组词被取消且窗口保留”，不据此宣称该分支完整通过。

下载 `KeepMD-0.6.0-windows-x64.zip`，解压后运行 `keepmd.exe` 或 `KeepPrompt.exe`。源码 ZIP 与 `v0.6.0` 标签对应，校验值见 SHA256SUMS。
