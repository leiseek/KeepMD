**KeepMD 0.7.0 版本说明**

0.7.0 聚焦阅读体验：围栏代码块原生语法着色与一键复制，界面信息收敛到标题栏，并修复最大化遮挡任务栏的问题。KeepMD 与 KeepPrompt 从本版起发布为两个互不包含的便携包。

- **代码块语法着色。** 围栏代码块按语言原生着色：关键字、常见内置类型与对象、字符串（含模板串与 Python 前缀串）、行/块注释、数字（进制、后缀、CSS 单位）、函数调用及 JSON/YAML/INI 的键各有颜色，注释为斜体。识别 C、C++、C#、Java、JavaScript、TypeScript、Python、Rust、Go、JSON、YAML、Shell、PowerShell、SQL、CSS 和 HTML/XML 及常见别名，浅色与深色主题各配一套颜色。词法扫描由内置代码完成，无第三方依赖；未知语言、缩进代码块和超大代码块保持单色，绝不改写文本——选择、查找和复制得到的仍是代码原文。
- **代码块一键复制。** 每个围栏代码块右上角有“复制”按钮：点击复制该块完整的围栏源码（不含 ``` 围栏行），按钮短暂显示“已复制”，悬停显示手型光标。右键菜单的“复制代码 / 图表源码”仍然可用。
- **标题栏承载文件名与模式。** 移除阅读器状态栏和页面卡片顶部的文件名/模式标签行；文件名与当前模式（阅读／可视化编辑／源码编辑）显示在自绘标题栏（如 `fix1.md — 阅读`），任务栏标题同步，未保存时文件名前有 `*`。保存、读取、磁盘变化警告、查找命中计数等瞬时消息在同一位置短暂出现，约 4 秒后恢复为模式；关闭查找栏即清除计数。工具栏按钮从 34×32 DIP 收窄为 30×26 DIP，正文起始位置提前，每屏多显示约一行。
- **最大化不再遮挡任务栏。** 修复双击标题栏最大化后任务栏与开始菜单被窗口盖住的问题：最大化矩形钳制到显示器工作区，窗口不再外扩覆盖整个监视器，系统不再把它当作全屏面直接合成；最大化状态下非客户区不再绘制。窗口化的细边框、Win+方向键贴靠与 F11 全屏（设计上覆盖整个显示器）行为不变。

**发布形式**

`KeepMD-0.7.0-windows-x64.zip` 只含阅读器 `keepmd.exe`；`KeepPrompt-0.7.0-windows-x64.zip` 只含提示词 `KeepPrompt.exe`。两个包各自携带使用说明、示例、许可证、验证结果与 SHA256SUMS，互不包含对方的程序或文件。升级 0.6.x 的便携目录时，两个包可以解压到同一目录，设置与草稿原位沿用。

验证：283 项核心检查（新增 9 项语法检查）与全部 GUI 测试套件在同一组 Release EXE 上通过，新增 `test_syntax.py` 真实窗口套件：两种主题下各类 token 颜色以像素断言渲染、从截图定位复制按钮、点击后剪贴板得到精确整块源码、“已复制”反馈可见。双击最大化往返两次（客户区与工作区四边相等、还原逐像素一致）、最大化状态下任务栏条带像素、F11 全屏与还原均有专项检查。完整数据见 [验证报告](../docs/VALIDATION.zh-CN.md)。

已知边界：语法着色只覆盖识别的语言子集，未知语言保持单色；HTML 原样显示块不着色。其余继承 0.6.0：公式只支持 MicroTeX 子集，Mermaid 只支持明确的 flowchart/graph 子集，未验证 Windows 10、ARM64 与物理跨显示器切换，便携程序未签名。

下载对应包，解压后运行 `keepmd.exe` 或 `KeepPrompt.exe`。源码 ZIP 与 `v0.7.0` 标签对应，校验值见各包内 SHA256SUMS。
